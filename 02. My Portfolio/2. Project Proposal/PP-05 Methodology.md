**Development approach***
This project will use a hybrid development approach that combines both Waterfall and Agile methodologies. The early stages of the project will follow a Waterfall structure, focusing on planning and design before development begins. This includes creating the project proposal, database schema, wireframes, and design documentation to provide a clear foundation for the project and reduce major changes later in development.

After the planning stage, the project will move into an Agile development process using weekly iterative sprints from Weeks 3–9. Each sprint will focus on implementing a specific group of features and will result in a working version of the application. At the end of each sprint, progress will be reviewed and reflected on through project journal entries to support continuous improvement throughout development.

***Project phases***
- Discovery - Define the problem, identify target users, research existing sleep tracking tools
- Design- Create wireframes/storyboards, ERD, DFDs, structure charts, data dictionary, class diagrams
- Development- Build features iteratively: auth -> models -> routes -> templates ->PWA   ->API.
- Testing - Manual test cases, W3C validation, DevTools verification (manifest, SW, cache).
- Review - Formal code review (peer + teacher), portfolio completion, final check
- Submission - Clone to offical repo, push portfolio to Github
