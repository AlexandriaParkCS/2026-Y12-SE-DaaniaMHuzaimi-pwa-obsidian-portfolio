Many teenagers and young adults struggle with poor or inconsistent sleep habits, yet lack a simple, private tool to track and reflect on their sleep patterns. This project proposes the development of **SleepTracker**, a secure, responsive Progressive Web Application (PWA) built using Python and Flask.

The application will allow users to create accounts, log sleep entries (bedtime, wake time, quality rating, and notes), set nightly sleep goals, and visualise their sleep patterns over time. All data will be stored in a SQLite database that complies with privacy and security best practices, including bcrypt password hashing, CSRF protection, input sanitisation, and user-controlled data deletion.

The project will follow an Agile methodology, combining an initial planning and design phase with iterative weekly development sprints. Deliverables will include a fully functional, installable PWA, a GitHub source code repository with a meaningful commit history, and this project portfolio documenting the design, implementation, testing, and reflection.

The estimated total cost of the project is $0, as all tools and technologies used are free and open source.
