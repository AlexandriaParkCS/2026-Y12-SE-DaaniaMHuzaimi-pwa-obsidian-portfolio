**Date:** 5 May 2026
**Project:** SleepTracker PWA
**Module:** Base template, auth templates, CSS theme system

**What I did:**
- Built `templates/base.html` using Jinja2 template inheritance with `{% block title %}`, `{% block content %}`, and `{% block scripts %}` blocks.
- Added a responsive Bootstrap 5.3 navbar with links using `{{ url_for('sleep.dashboard') }}`, `{{ url_for('sleep.log_sleep') }}`, `{{ url_for('sleep.history') }}`, `{{ url_for('sleep.goal') }}`, and `{{ url_for('auth.logout') }}`.
- Added a skip link (`<a href="#main-content" class="skip-link">Skip to content</a>`) as the first focusable element for keyboard and screen reader accessibility.
- Added a theme toggle `<button>` with `aria-label="Toggle theme"` and icons for each theme state (☾ dark / ☀ light / ♥ purple).
- Added a `<footer>` with `role="contentinfo"` and a privacy link using `{{ url_for('sleep.privacy') }}`.
- Built `templates/login.html` and `templates/register.html`, each with `{{ form.hidden_tag() }}` for CSRF, `<label>` elements for every input field (not placeholder-only), and `{% for error in field.errors %}` loops for validation error display.
- Wrote `static/css/style.css` using CSS custom properties (`--bg-color`, `--text-color`, `--card-bg`, `--accent`) on the `[data-theme]` attribute selector, with three rulesets: `[data-theme="dark"]`, `[data-theme="light"]`, `[data-theme="purple"]`.

**Why I did it:**
- `url_for()` is used instead of hardcoded paths (e.g. `/dashboard`) because if a route URL changes, only the route decorator needs updating all `url_for()` calls resolve correctly automatically. Hardcoded paths would require finding and updating every template.
- CSS custom properties on the `<html>` element (via `data-theme`) were chosen over a Flask session theme approach because the theme is a client-side preference switching it with localStorage and JavaScript is instant and works offline, whereas a Flask session approach would require a server round-trip for every theme change.
- `<label>` elements (not just `placeholder` text) are required for accessibility: screen readers announce label text when a form field receives focus, whereas placeholder text is often ignored or announced inconsistently.
- `{{ form.hidden_tag() }}` renders the CSRF token  without it, Flask-WTF rejects all POST requests with a 400 Bad Request error.

**Challenges:**
- Initially wrote `<html data-theme="dark">` hardcoded in the template. This meant JavaScript couldn't control the initial theme from localStorage on page load  the hardcoded value would override it until the JS ran, causing a flash of the wrong theme. Fixed by removing `data-theme` from the HTML tag entirely and letting `app.js` set it from localStorage immediately.
- Bootstrap 5.3 local files (`bootstrap.min.css` and `bootstrap.bundle.min.js`) needed to be in `static/css/` and `static/js/` respectively. Initially referenced them with a relative path that broke on any route deeper than root. Fixed using `{{ url_for('static', filename='css/bootstrap.min.css') }}`.
